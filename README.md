# NXR_Flayer Official Esports Website

Personal-brand esports hub for **NXR_Flayer**, competitive Roblox Rivals player and knifer representing Bangladesh.

---

## 1. Local Testing on Windows

Because this project uses static HTML5, CSS3, and modern vanilla JavaScript, no heavy installation or build steps are required.

### Option A: Using VS Code Live Server (Fastest)
1. Install [VS Code](https://code.visualstudio.com/).
2. Install the **Live Server** extension by Ritwick Dey.
3. Open this folder in VS Code, right-click `index.html`, and select **Open with Live Server**.

### Option B: Using Python on Windows Command Prompt
If you have Python installed:
```cmd
cd path\to\nxr-flayer-website
python -m http.server 8000
